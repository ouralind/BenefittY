## 📌 О проекте

[Benefitty](https://benefitty.ru/) — платформа, которая объединяет бизнес и пользователей в единую экосистему программ лояльности. Продукт включает веб-приложение, мобильные приложения, Mini Apps, административную панель и API.

**Моя роль:** Manual QA Engineer  
**Период:** 2023 — настоящее время

## 🧩 Что входило в продукт

| Компонент | Область тестирования |
|:--|:--|
| 🌐 Web | Пользовательские сценарии, бизнес-логика |

| 💳 Payment Integrations | Платежи и взаимодействие с внешними сервисами |

## 🔍 Чем я занималась

**Функциональное и регрессионное тестирование**
- Проверка новых функций и существующих пользовательских сценариев.
- Тестирование бизнес-логики, граничных и негативных сценариев.
- Регрессионное тестирование перед релизами.

**API и интеграции**
- Тестирование REST API с использованием Postman и Swagger.
- Проверка авторизации через СберБизнес, Альфа ID и ВТБ ID.
- Тестирование интеграций с кассовыми системами iiko, Frontol и Штрих-М.

**Платежи и бизнес-логика**
- Проверка полного сценария оплаты и активации платного доступа.
- Проверка передачи данных между платёжным сервисом и amoCRM.
- Валидация обновления тарифов и связанных данных в PostgreSQL.

**Анализ данных и диагностика**
- Проверка данных в базе PostgreSQL с помощью SQL-запросов.
- Анализ логов и ошибок в Grafana и Kibana.
- Использование DevTools и Charles для анализа сетевых запросов.

- Анализ требований и уточнение неоднозначных сценариев.
