## 📌 О проекте

[Benefitty](https://benefitty.ru/) — финтех-экосистема, объединяющая бизнес и пользователей через программы лояльности, скидки, банковские предложения и платежные решения.

В рамках проекта я занималась тестированием нескольких взаимосвязанных компонентов: от пользовательских приложений до административной панели, API и внешних интеграций.

**Роль:** Manual QA Engineer  
**Период:** 2023 — настоящее время

---


## 🧩 Архитектура продукта и зоны тестирования

Benefitty — экосистема, объединяющая пользовательские и бизнес-сервисы, программы лояльности, банковские предложения и инструменты для управления компаниями. Продукт включает несколько взаимодействующих компонентов, доступных на разных платформах.

### 🌐 Web Application

Веб-платформа с отдельными личными кабинетами для пользователей и представителей бизнеса.

**Основная функциональность:**
- Личный кабинет пользователя: профиль, карты лояльности, скидки и банковские предложения, добавление чеков.
- Личный кабинет бизнеса: управление компанией, заведениями и предложениями, создание постов и пуш-уведомлений, настройка программ лояльности и кассовых интеграций, отслеживание аналитики, работа с отзывами.
- Просмотр и использование акций, программ лояльности и банковских предложений.
- Поиск заведений и использование местоположения.
- Социальные функции: лента новостей, публикации, отзывы, друзья и возможность делиться картами лояльности и скидками.
- Получение уведомлений.
- Управление тарифами и платными возможностями.
- Покупка Premium-подписки.
- Процессинг программ лояльности через Benefitty.
- Взаимодействие с AI-помощником.
- Настройка интеграции с сервисом ФНС России «Мои чеки онлайн». 

**Что тестировала:**
- Пользовательские сценарии и бизнес-логику.
- Авторизацию и разграничение доступа.
- Корректность отображения и обновления данных.
- Взаимодействие с API и внешними сервисами.
- Сквозные сценарии между пользовательской и бизнес-частями платформы.

### 🤖 AI Assistant

AI-помощник, интегрированный в экосистему Benefitty и предназначенный для взаимодействия с пользователями через текстовые запросы.

**Основная функциональность:**
- Отправка пользовательских запросов.
- Получение и отображение ответов AI-помощника.
- Обработка контекста диалога.
- Взаимодействие с серверной частью через API.

**Что тестировала:**
- Отправку запросов и получение ответов.
- Корректность обработки пользовательского ввода.
- Обработку последовательных запросов и контекста диалога.
- Поведение помощника при пустых, некорректных и неоднозначных запросах.
- Обработку ошибок API и серверных ошибок.
- Поведение при отсутствии интернет-соединения.
- Отображение состояний загрузки и результатов выполнения запросов.
- Корректность обработки повторных запросов.

**Основная функциональность:**
- Авторизация и управление профилем.
- Просмотр компаний, заведений и доступных предложений.
- Просмотр и использование карт лояльности, скидок и банковских предложениий.
- Поиск заведений и использование местоположения.
- Получение уведомлений.
- Создание публикаций, добавление изображений и оставление отзывов.
- Добавление чеков. 
- Покупка Premium-подписки.
- Настройка интеграции с сервисом ФНС России «Мои чеки онлайн». 

**Что тестировала:**
- Функциональность и пользовательские сценарии.
- Корректность отображения интерфейса на разных устройствах.
- Навигацию и переходы между экранами.
- Обработку ошибок и нестандартных ситуаций.
- Регрессионные сценарии после внесения изменений.

### 💳 Платежи и внешние интеграции

В продукте реализовано взаимодействие с банковскими сервисами, платёжными системами и кассовым ПО.

**Банковские интеграции:**
- СберБизнес
- Альфа ID
- ВТБ ID
- ФНС России — сервис «Мои чеки онлайн» (автоматическая загрузка чеков)

**Кассовые интеграции:**
- iiko
- Frontol
- Штрих-М

**Что тестировала:**

*Интеграции с внешними сервисами:*
- Авторизацию пользователей через внешние банковские сервисы.
- Корректность обработки ответов интеграций.
- Передачу данных между системами.

*Платежи и тарифы:*
- Оплату Premium-подписки и других платных возможностей банковской картой и по счёту.
- Изменение статусов платёжных операций.
- Активацию тарифов после успешной оплаты.
- Сохранение и обновление информации о тарифах в системе.
- Формирование УПД.

*Кассовые интеграции:*
- Взаимодействие с кассовым ПО.
- Обмен данными между компонентами системы.
- Корректность применения скидок и начисления бонусов.
- Обработку операций при различных результатах взаимодействия с кассовыми системами.

*Программы лояльности:*
- Начисление и списание бонусных баллов.
- Применение скидок в рамках программ лояльности.
- Предварительное начисление баллов за настроенные события, например день рождения пользователя.
- Отмену начисления и списания баллов при возврате покупки.
- Сгорание баллов в соответствии с условиями программы лояльности.
- Корректность изменения бонусного баланса после выполнения операций.

*Интеграция с ФНС России:*
- Автоматическую загрузку чеков через сервис «Мои чеки онлайн».
- Корректность обработки данных, полученных от внешнего сервиса.

### 💬 Chat & Messaging

Модуль обмена сообщениями между пользователями с поддержкой обновления переписки в реальном времени.

**Основная функциональность:**
- Отправка и получение сообщений.
- Отображение статусов сообщений и прочтения.
- Обновление переписки без перезагрузки страницы.
- Индикатор набора сообщения собеседником.
- Работа с событиями и обновлениями через Server-Sent Events (SSE).

**Что тестировала:**
- Отправку, получение и отображение сообщений.
- Обновление переписки и обработку SSE-событий.
- Корректность отображения статусов отправки и прочтения.
- Обработку повторной отправки сообщений.
- Восстановление соединения и получение обновлений после переподключения.
- Негативные сценарии при отсутствии интернет-соединения и ошибках сервера.
- Поведение интерфейса при неудачной отправке сообщений.
- Сохранение и восстановление состояния переписки после обновления страницы.
- Отображение ошибок и корректность доступных пользователю действий при сбоях.

Мини-приложения внутри мессенджеров и социальных платформ, предоставляющие доступ к возможностям Benefitty без установки отдельного приложения.

**Основная функциональность:**
- Поиск компаний и заведений.
- Просмотр скидок и специальных предложений.
- Работа с картами лояльности.
- Регистрация и авторизация через платформы.

**Что тестировала:**
- Пользовательские сценарии и навигацию.
- Поиск и фильтрацию предложений.
- Корректность отображения данных и работы карточек.
- Интеграцию с API и передачу параметров.
- Регистрацию и авторизацию через внешние платформы.
- Поведение интерфейса при различных условиях использования.
